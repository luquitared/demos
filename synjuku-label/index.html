▸ Task brief & labeling rules (read me first)
Watch the whole clip, then break it into sequential action blocks that cover the timeline with no gaps. One dominant hand action per block.
  • Name objects from the picker, not free text. Use the same object name every time you refer to it — pick “other” only when nothing fits.

  • Label hand-to-hand transfers as their own block (type = transfer) whenever an object moves between hands.
  • Completion signal must reference the same object as the description.
  • Mark outcome & confidence honestly — not everything is “success / High”. Use partial / failure and lower confidence when the view is unclear.
